# J3C Rental Properties

Latest update:
- Unit numbers are no longer shown on the public Available Units / property cards.
- Public property search no longer searches by unit number, and the search prompt now says "Property, building or location".
- The public card shows building/floor information instead of the private unit number.
- Unit numbers are still retained in the database and Admin dashboard for internal management; the Admin field is labeled "Unit no. (Admin only)".
- Existing Locations show-all behavior, location-photo management, inquiry/contact flow, and database-backed content are preserved.
